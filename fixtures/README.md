# Fixtures — the golden weeks

**Not built yet.** This file describes what Phase 1 writes first (`docs/PHASE-1-PLAN.md`). Every company, person, deal, address and figure is invented for Tallgrass Advisory (fictional); domains are `.example`, plus `.test` for records deliberately outside the demo set. Nothing here describes a real business.

## Layout (Phase 1)

| Path | What |
|---|---|
| `spec.js` | the source: per golden week, the compact inputs from PRD §9 (series values, deals with stage history, contacts, tasks, sheet rows, ledger rows, run time, injected failures) and a hand-typed `expected` block |
| `build.js` | expands `spec.js` into raw HubSpot-shaped pages and Sheets `values` arrays; `--check` fails on drift |
| `weeks/<id>.json` | the inputs one run sees: `runAt`, `deals`, `contacts`, `tasks` (as `GET /crm/v3/objects/...` results), `sheet` and `definitions` (`values` arrays), `ledger` (`runs` tab values), `hubspotFailures` (E20) |
| `expected/<id>.json` | written unchanged by `build.js` from the `expected` block **typed by hand in `spec.js` from PRD §9**: metric values, comparison renderings, flags, check result (pass or first reason), outcome (`done` / `metrics_only` / `failed`), model call count. Never generated by the engine |
| `recorded/<id>.json` | **hand-written stand-ins for the model's `write_pulse` tool input, not model output**, with `usage` token counts that are characters/4 estimates, not measurements. Absent for E02 (quiet), E16 (cap) and E20 (failure) |
| `weeks/E01-truncated.json` | input variant: two pages of deals with `hubspotMaxPages` 1, for `hubspot_truncated` |
| `recorded/variants/E01-*.json` | one stand-in each for `schema`, `too_long`, `number_in_suggestion`, `spelled_number`, `unverifiable_claim` on E01's inputs |
| `index.json` | id, title, outcome, reason per golden week |
| `test-config.json` | the config used by the tests (fake folder and sheet ids, `ownerEmail` on `.example`) |

## Calendar

Report week `2026-11-16` (Monday) to `2026-11-23`, America/Chicago: `startUtc 2026-11-16T06:00:00Z`, `endUtc 2026-11-23T06:00:00Z`. Prior weeks `2026-10-19`, `10-26` (169 hours, DST ends 2026-11-01), `11-02`, `11-09`. Default `runAt` `2026-11-23T16:00:00Z` (Monday 10:00 CST, the schedule).
